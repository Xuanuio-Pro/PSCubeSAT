# Nội dung Lab 4 (khung rỗng)

Mỗi mục của Lab 4 có một file riêng để bổ sung nội dung sau. Bổ sung xong, chạy `npm run curriculum:export`
rồi `npm run curriculum:seed` (hoặc khởi động lại backend để seed phiên bản mới).

| Mục (ID bài) | File | Nội dung cần điền |
|---|---|---|
| Video 4.1 - 4.5 (`video-4-1` ... `video-4-5`) | `video-4-1.json` ... `video-4-5.json` | `url`, `duration_seconds` |
| Doc 4.1 (`document-4-1`) | `doc-4-1.md` | Markdown tài liệu |
| Doc 4.2 (`document-4-imu`) | `doc-4-2.md` | Markdown tài liệu |
| Doc 4.3 (`document-4-gnss`) | `doc-4-3.md` | Markdown tài liệu |
| Doc 4.4 (`document-4-2`) | `doc-4-4.md` | Markdown tài liệu |
| Doc 4.5 (`document-4-camera`) | `doc-4-5.md` | Markdown tài liệu |
| Doc 4.6 (`document-4-3`) | `doc-4-6.md` | Markdown tài liệu |
| Doc 4.7 (`document-4-sensors`) | `doc-4-7.md` | Markdown tài liệu |

Bài thực hành `Lab4-01a` ... `Lab4-06_Read_All_Sensors` dùng mã `.cpp` ở thư mục cha.
Các mục `quiz-doc-4-*`, `quiz-practice-4-*` và `labtest-4` tự nạp câu mẫu từ server (`../default-question-bank.csv`:
3 câu xoay vòng cho mỗi quiz, 10 câu cho Lab Test); đáp án chỉ lưu ở server.
