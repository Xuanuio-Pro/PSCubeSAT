# Nội dung Lab 3 (khung rỗng)

Mỗi mục của Lab 3 có một file riêng để bổ sung nội dung sau. Bổ sung xong, chạy `npm run curriculum:export`
rồi `npm run curriculum:seed` (hoặc khởi động lại backend để seed phiên bản mới).

| Mục (ID bài) | File | Nội dung cần điền |
|---|---|---|
| Video 3.1 - 3.4 (`video-3-1` ... `video-3-4`) | `video-3-1.json` ... `video-3-4.json` | `url`, `duration_seconds` |
| Doc 3.1 - 3.4 (`document-3-1`, `document-3-cli`, `document-3-3`, `document-3-4`) | `doc-3-1.md` ... `doc-3-4.md` | Markdown tài liệu |

Bài thực hành `Lab3-01a` ... `Lab3-05_Event_Driven_Queue` dùng mã `.cpp` ở thư mục cha.
Các mục `quiz-doc-3-*`, `quiz-practice-3-*` và `labtest-3` tự nạp câu mẫu từ server (`../default-question-bank.csv`:
3 câu xoay vòng cho mỗi quiz, 10 câu cho Lab Test); đáp án chỉ lưu ở server.
