# Nội dung Lab 7 (khung rỗng)

Mỗi mục của Lab 7 có một file riêng để bổ sung nội dung sau. Bổ sung xong, chạy `npm run curriculum:export`
rồi `npm run curriculum:seed` (hoặc khởi động lại backend để seed phiên bản mới).

| Mục (ID bài) | File | Nội dung cần điền |
|---|---|---|
| Video 7.1, 7.2 (`video-7-1`, `video-7-2`) | `video-7-1.json`, `video-7-2.json` | `url`, `duration_seconds` |
| Doc 7.1 - 7.3 (`document-7-1` ... `document-7-3`) | `doc-7-1.md` ... `doc-7-3.md` | Markdown tài liệu |

Bài thực hành `Lab7-01_Full_Satellite_Program`, `Lab7-02_RTOS_Satellite_System` dùng mã `.cpp` ở thư mục cha.
Các mục `quiz-doc-7-*`, `quiz-practice-7-*` và `labtest-7` tự nạp câu mẫu từ server (`../default-question-bank.csv`:
3 câu xoay vòng cho mỗi quiz, 10 câu cho Lab Test); đáp án chỉ lưu ở server.
