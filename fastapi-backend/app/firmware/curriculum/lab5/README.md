# Nội dung Lab 5 (khung rỗng)

Mỗi mục của Lab 5 có một file riêng để bổ sung nội dung sau. Bổ sung xong, chạy `npm run curriculum:export`
rồi `npm run curriculum:seed` (hoặc khởi động lại backend để seed phiên bản mới).

| Mục (ID bài) | File | Nội dung cần điền |
|---|---|---|
| Video 5.1 - 5.3 (`video-5-1` ... `video-5-3`) | `video-5-1.json` ... `video-5-3.json` | `url`, `duration_seconds` |
| Doc 5.1 (`document-5-1`) | `doc-5-1.md` | Markdown tài liệu |
| Doc 5.2 (`document-5-lora`) | `doc-5-2.md` | Markdown tài liệu |
| Doc 5.3 (`document-5-2`) | `doc-5-3.md` | Markdown tài liệu |

Bài thực hành `Lab5-01a` ... `Lab5-03_Ground_Station_Demo` dùng mã `.cpp` ở thư mục cha.
Các mục `quiz-doc-5-*`, `quiz-practice-5-*` và `labtest-5` tự nạp câu mẫu từ server (`../default-question-bank.csv`:
3 câu xoay vòng cho mỗi quiz, 10 câu cho Lab Test); đáp án chỉ lưu ở server.
