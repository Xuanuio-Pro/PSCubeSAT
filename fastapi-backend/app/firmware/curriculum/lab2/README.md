# Nội dung Lab 2 (khung rỗng)

Mỗi mục của Lab 2 có một file riêng để bổ sung nội dung sau. Bổ sung xong, chạy `npm run curriculum:export`
rồi `npm run curriculum:seed` (hoặc khởi động lại backend để seed phiên bản mới).

| Mục (ID bài) | File | Nội dung cần điền |
|---|---|---|
| Video 2.1, 2.2 (`video-2-1`, `video-2-2`) | `video-2-1.json`, `video-2-2.json` | `url`, `duration_seconds` |
| Doc 2.1, 2.2 (`document-2-1`, `document-2-2`) | `doc-2-1.md`, `doc-2-2.md` | Markdown tài liệu |

Bài thực hành `Lab2-01a_Battery_I2C`, `Lab2-01b_Battery_Library`, `Lab2-02_Power_Saving` dùng mã `.cpp` ở thư mục cha.
Các mục `quiz-doc-2-*`, `quiz-practice-2-*` và `labtest-2` tự nạp câu mẫu từ server (`../default-question-bank.csv`:
3 câu xoay vòng cho mỗi quiz, 10 câu cho Lab Test); đáp án chỉ lưu ở server.
