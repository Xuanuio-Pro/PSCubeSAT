# Nội dung Lab 6 (khung rỗng)

Mỗi mục của Lab 6 có một file riêng để bổ sung nội dung sau. Bổ sung xong, chạy `npm run curriculum:export`
rồi `npm run curriculum:seed` (hoặc khởi động lại backend để seed phiên bản mới).

| Mục (ID bài) | File | Nội dung cần điền |
|---|---|---|
| Video 6.1, 6.2 (`video-6-1`, `video-6-2`) | `video-6-1.json`, `video-6-2.json` | `url`, `duration_seconds` |
| Doc 6.1 - 6.3 (`document-6-1` ... `document-6-3`) | `doc-6-1.md` ... `doc-6-3.md` | Markdown tài liệu |

Thực hành lắp ráp khung cơ khí (`assembly-6`) có thể cấu hình hướng dẫn và rubric trực tiếp trên `/classes`.
Các mục `quiz-doc-6-*`, `quiz-practice-6-frame` và `labtest-6` tự nạp câu mẫu từ server (`../default-question-bank.csv`:
3 câu xoay vòng cho mỗi quiz, 10 câu cho Lab Test); đáp án chỉ lưu ở server.
