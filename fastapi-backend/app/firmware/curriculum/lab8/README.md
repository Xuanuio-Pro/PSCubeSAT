# Nội dung Lab 8 (khung rỗng)

Mỗi mục của Lab 8 có một file riêng để bổ sung nội dung sau. Bổ sung xong, chạy `npm run curriculum:export`
rồi `npm run curriculum:seed` (hoặc khởi động lại backend để seed phiên bản mới).

| Mục (ID bài) | File | Nội dung cần điền |
|---|---|---|
| Video 8.1, 8.2 (`video-8-1`, `video-8-2`) | `video-8-1.json`, `video-8-2.json` | `url`, `duration_seconds` |
| Doc 8.1 (`document-8-1`) | `doc-8-1.md` | Markdown tài liệu |
| Doc 8.2 (`document-8-widgets`) | `doc-8-2.md` | Markdown tài liệu |
| Doc 8.3 (`document-8-2`) | `doc-8-3.md` | Markdown tài liệu |

Bài thực hành `Lab8-01_Custom_Mission` dùng mã `.cpp` ở thư mục cha.
Các mục `quiz-doc-8-*`, `quiz-practice-8-capstone` và `labtest-8` tự nạp câu mẫu từ server (`../default-question-bank.csv`:
3 câu xoay vòng cho mỗi quiz, 10 câu cho Lab Test); đáp án chỉ lưu ở server.
