# PSCubeSAT Frontend

Giao diện React/Vite của PTIT-STEM-CUBE.

## Chạy giao diện

```sh
npm ci
npm run dev
```

Mở http://localhost:5175. Các API và WebSocket được chuyển tiếp đến backend tại http://127.0.0.1:8005; cần chạy backend riêng để sử dụng đăng nhập và các chức năng máy chủ.

## Kiểm tra và build

```sh
npm run lint
npm run build
```
